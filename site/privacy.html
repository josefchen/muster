Privacy.

Updated 19 October 2026.

The app

Muster has no accounts and sends no analytics. Local session data stays on your Mac. Agent hooks communicate with Muster over localhost.

Version 1.4, currently in development, adds optional SSH monitoring. Only hosts you enable are contacted. Titles, project paths, status and question previews travel over encrypted SSH to your Mac and stay in memory. Full transcripts are not copied. Host settings, a connection identifier and read/unread timestamps keyed by session ID are saved on this Mac. Monitoring uses your existing SSH access and installs no remote hooks.

If you separately enable remote approvals, a small Python hook is installed on that host and its agent settings are updated with backups. Pending tool requests, commands, question choices and your answers travel over the same encrypted SSH connection and stay in memory. A private Unix socket connects the remote hook; no network port is opened. When Muster disconnects, the agent asks normally. Remote approvals can be removed with the setup script.

If you enable update checks, Muster asks GitHub for the latest release. GitHub receives the network request, including your IP address. You can turn update checks off in Settings.

This website

We count page loads, download-link clicks and successful copies of the Homebrew command to learn how people find Muster. We store daily totals grouped by a fixed page name, event and broad source such as Hacker News or GitHub.

We set no analytics cookies, use no browser storage, and create no visitor identifiers or fingerprints. We do not store individual events, IP addresses, user agents, full URLs, search terms or full referrers in the measurement database. Unrecognized sources are grouped as “other”.

Do Not Track and Global Privacy Control disable this measurement. Counts are approximate: a download click does not confirm a download or installation, and we cannot identify returning visitors or active app users.

The aggregate database is hosted in Cloudflare’s EU jurisdiction. Daily totals are deleted after 90 days. Cloudflare serves this website and necessarily processes network requests; its infrastructure and security processing are separate from our aggregate counters. Worker request logging and Logpush are disabled for the site.

The GitHub star count is fetched by our server. Your browser does not contact GitHub just to display it. Following a GitHub link or downloading Muster takes you to GitHub, which has its own privacy policy.

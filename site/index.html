⌥Tab

Hold ⌥ and tap Tab. The session that needs you is first, and letting go opens it.

⌥↩

Answer without switching.

When an agent wants to run a command, the request shows up at the top of whichever screen you're on. Allow it from there, or deny it with ⌥⌫. Questions and plan approvals work the same way.

Works with Claude Code and Codex once you turn it on.

⌃⌥Space

Find any session.

Every session from the last three hours, in one list. Start typing to narrow it down.

Each one shows its tokens and what they would cost at API list prices. On a Max or Pro plan you don't pay that, but it tells you which sessions are the expensive ones.

Nothing leaves your Mac.

Muster reads the session files your agents already write. An agent's question reaches Muster over localhost, and your answer goes back the same way. There's no account and no analytics, and the update check stays off until you turn it on.
